# FLS Analyzer

Web app per analizzare la Field Level Security (FLS) di Salesforce e modificarla in blocco su più campi e più profili/permission set, con anteprima, approvazione in produzione, esecuzione a lotti e rollback.

- Mockup interattivo (aprilo nel browser): [docs/mockup.html](docs/mockup.html)
